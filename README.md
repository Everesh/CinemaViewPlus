# CinemaViewPlus
YouTube stylesheet targeting cinemaview. Less UI, more video player.

## Installation
1. Make sure you have stylus
   - [for firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)
   - [for chrome](https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne?hl=en)
2. Install the style
   - [via this repo](https://github.com/Everesh/CinemaViewPlus/raw/refs/heads/main/stylesheet.user.css)
   - [via userstyles.world](https://userstyles.world/api/style/24332.user.css)
